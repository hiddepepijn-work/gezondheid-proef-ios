# Gezondheid proef voor de iPhone (SideStore-bron)

Deze repo bevat geen code. Alleen de release **ios-latest** met de ongetekende `gezondheid-proef.ipa`
en `source.json`. De code staat in een privé-repo; daarom staat de build hier, waar SideStore hem
zonder inlog kan ophalen.

## Installeren

1. SideStore, tabblad **Sources**, **+**, plak:
   `https://github.com/hiddepepijn-work/gezondheid-proef-ios/releases/download/ios-latest/source.json`
2. Tik **Gezondheid proef**, installeren. Updates verschijnen onder My Apps.

Gratis Apple ID: maximaal 3 actieve apps (SideStore telt mee).
